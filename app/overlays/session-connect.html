StreamElements connection

One small add-on, identical for all five StreamElements overlays. It forwards chat and session events to your local overlays. Your existing widget remains visible until the relay connects. Then HTML draws the layout, using the same StreamElements events.

  1. Copy the code below.
  2. Open a StreamElements overlay → Custom Widget → Open Editor → JS.
  3. If you already added an older loraii relay, replace that relay block with this one. Otherwise paste this AFTER your existing widget code, then save.
  4. Repeat for the other four overlays. You do not need a sixth overlay for Just Chatting.

Send a real Twitch message after saving Gameplay. The controller's Session section shows when it receives events. Credits only contain names received after this connection starts; no viewer list is invented.
