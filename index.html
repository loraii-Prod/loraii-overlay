Bracket controller

Setting this up in OBS Add this file as a Browser Source at 1920×1080 with “Local file” ticked. It shows whichever part is on air here, on a transparent background unless the fire backdrop is on. Then add it again as a Custom Browser Dock with #control on the end of the address to get this controller inside OBS. Both share storage, so changes reach the stream within a second. One source on its own: add #rotate=20&sheet to switch parts every 20 s and pull scores from the sheet, or make the source 1920×1160, crop 80 px off the bottom, and use the Part 1 / Part 2 buttons below the picture through right-click → Interact (keys 1 / 2 work too). Use #part1 or #part2 to lock a source to one part.
